## Purpose

Даёт админу единую годовую сводку по всей системе сразу: сколько был оборот, сколько заработали трейдеры и
сколько заработала система, помесячно, без необходимости пролистывать каждый месяц по отдельности.

## ADDED Requirements

### Requirement: Помесячный оборот за год по всей системе
Система SHALL показывать на годовой сводке, для каждого месяца выбранного года, суммарные покупки, продажи и
оборот (покупки + продажи) в рублях, посчитанные по ордерам ВСЕХ пользователей сразу, а не одного за раз.

#### Scenario: Открытие годовой сводки
- **WHEN** админ открывает годовую сводку за 2026 год
- **THEN** система показывает таблицу с 12 строками (по одной на месяц), в каждой — сумма покупок, продажа и
  оборот в рублях по всем пользователям, плюс итоговая строка за весь год

#### Scenario: Месяц без данных
- **WHEN** в месяце нет ни одного ордера (месяц раньше начала учёта системы или ещё не наступил)
- **THEN** система показывает для этого месяца нулевые покупки, продажи и оборот, не пропуская строку месяца

#### Scenario: Применение фильтров
- **WHEN** админ выбирает фильтр по бирже, банку или валюте
- **THEN** суммы по всем 12 месяцам и итоговая строка пересчитываются с учётом фильтра

### Requirement: Помесячная прибыль трейдеров и доход системы
Система SHALL показывать на годовой сводке, для каждого месяца, грязную прибыль трейдеров (доход от сделок за
вычетом себестоимости и комиссий), чистую прибыль трейдеров (грязная прибыль за вычетом налога) и доход системы
(её долю от чистой прибыли трейдеров) — суммарно по всем пользователям.

#### Scenario: Прибыль и доход системы видны на той же странице
- **WHEN** админ открывает годовую сводку
- **THEN** для каждого месяца, помимо оборота, видны: грязная прибыль трейдеров, чистая прибыль трейдеров, доход
  системы — в рублях

#### Scenario: Расчёт согласован с помесячной страницей по одному пользователю
- **WHEN** значения грязной/чистой прибыли за конкретный месяц суммируются по всем пользователям вручную (через
  существующую помесячную страницу «Прибыль» по каждому пользователю за тот же месяц)
- **THEN** сумма совпадает с тем, что показывает годовая сводка за этот месяц (в пределах округления)

### Requirement: Годовая сводка остаётся быстрой
Открытие годовой сводки SHALL не блокировать браузер админа длительным ожиданием — время отклика страницы
SHALL оставаться в пределах нескольких секунд независимо от того, насколько дорог расчёт прибыли по всем
пользователям и месяцам.

#### Scenario: Загрузка страницы не занимает минуты
- **WHEN** админ открывает годовую сводку с посчитанной прибылью
- **THEN** страница отображается пользователю без ожидания в духе полного пересчёта LIFO по всем ~140+
  пользователям за все 12 месяцев синхронно в рамках одного HTTP-запроса

#### Scenario: Устаревшие данные допустимы, но не скрыты
- **WHEN** значения прибыли получены не в реальном времени (посчитаны заранее/в фоне)
- **THEN** админ может понять, что это не мгновенный расчёт по последним ордерам (например по времени последнего
  обновления или иному явному признаку), а не считает молча устаревшие цифры свежими
