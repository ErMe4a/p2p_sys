## Purpose

Хранит пол пользователя в профиле, чтобы документы, которые система формирует от его имени, правильно
согласовывались по роду («принимал/принимала» и т.п.).

## ADDED Requirements

### Requirement: Поле «Пол» в профиле пользователя
Система SHALL хранить для каждого пользователя необязательное поле «Пол» со значениями «Мужской» и
«Женский». Поле SHALL быть доступно для просмотра и изменения на странице настроек `/settings/` рядом с ФИО.
У существующих пользователей поле SHALL быть пустым, пока его не заполнят.

#### Scenario: Пользователь указывает пол в настройках
- **WHEN** пользователь выбирает пол на странице настроек и сохраняет форму
- **THEN** выбранное значение сохраняется и отображается при следующем открытии настроек

#### Scenario: Существующий пользователь после обновления
- **WHEN** обновление выкатывается на сервер
- **THEN** у всех существующих пользователей поле «Пол» пустое, остальные данные профиля не меняются, и
  сохранение настроек работает как раньше, даже если пол не выбран

#### Scenario: Пол сбрасывается
- **WHEN** пользователь выбирает в поле пустое значение («не указан») и сохраняет настройки
- **THEN** поле «Пол» становится пустым
