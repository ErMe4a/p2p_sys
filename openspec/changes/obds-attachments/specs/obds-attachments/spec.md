## Purpose

Хранит файлы по делу ОБДС трейдера: решения ЦБ и PDF со скринами сделок к записям переводов. Собирает «Запрос
данных по ОБДС» сам: REQ берутся из базы по банку-адресату, решения ЦБ прикладываются как приложения.

## ADDED Requirements

### Requirement: Решения ЦБ трейдера
В блоке «База данных ОБДС» верхним пунктом система SHALL позволять админу загружать для выбранного пользователя
PDF-файлы «Решение ЦБ». Привязки к REQ нет: одно решение покрывает несколько операций. Решения хранятся списком в
порядке загрузки. Каждое SHALL можно скачать, заменить новым файлом и удалить. Принимаются только PDF до 20 МБ.

#### Scenario: Загрузка решения
- **WHEN** админ выбирает пользователя и загружает PDF
- **THEN** решение появляется в списке («Решение №N», имя файла, «Скачать», «Заменить», «Удалить»)

#### Scenario: Замена файла решения
- **WHEN** админ заменяет файл существующего решения
- **THEN** у решения новый файл, старый удалён, число решений не изменилось

#### Scenario: Не PDF или слишком большой файл
- **WHEN** админ пытается загрузить файл не в формате PDF или больше 20 МБ
- **THEN** файл не сохраняется, и в блоке показывается причина

### Requirement: PDF сделки у записи перевода
Система SHALL позволять прикрепить к каждой записи ОБДС один PDF со скринами сделки, скачать его, заменить и
удалить. Ограничения те же: PDF, до 20 МБ. При удалении записи её файл SHALL удаляться вместе с ней.

#### Scenario: Прикрепление PDF к записи
- **WHEN** админ загружает PDF у записи перевода
- **THEN** у записи появляется отметка о файле и ссылка «Скачать»

#### Scenario: Удаление записи с файлом
- **WHEN** админ удаляет запись, к которой прикреплён PDF
- **THEN** запись и её файл удаляются

### Requirement: REQ подставляются автоматически по банку-адресату
В форме «Запрос данных по ОБДС» SHALL быть только поле «Банк (кому)». Номера запросов вручную не вводятся.
Система SHALL брать идентификаторы (REQ) всех операций пользователя, где выбранный банк выступает банком-
отправителем: название сравнивается без учёта регистра и лишних пробелов, дубли убираются, порядок — порядок
записей. Номера перечисляются в документе через запятую: «по запросу REQ-1, REQ-2.». Если таких операций нет,
документ SHALL не формироваться, а админ видит сообщение.

#### Scenario: Банк-отправитель в двух операциях
- **WHEN** у пользователя две операции, где «ПАО Сбербанк» — банк-отправитель (REQ-1 и REQ-2), и одна, где он —
  банк-получатель (REQ-3), и админ формирует запрос в «ПАО Сбербанк»
- **THEN** в документе стоит «по запросу REQ-1, REQ-2.», REQ-3 не попадает

#### Scenario: Нет операций с этим банком-отправителем
- **WHEN** админ выбирает банк, который ни в одной операции пользователя не является банком-отправителем
- **THEN** документ не скачивается, и показывается сообщение об этом

### Requirement: Нумерованные приложения и скачивание вместе с решениями
В разделе «Приложения:» документа система SHALL выводить отдельную строку на каждое решение ЦБ пользователя в
порядке загрузки: «Приложение №1: Решение ЦБ об отказе в исключении данных из базы», «Приложение №2: …». Если
решений нет, раздел остаётся как в шаблоне Максима.

«Скачать PDF» SHALL отдавать один PDF: обращение, затем страницы решений в порядке нумерации. «Скачать Word» при
наличии решений SHALL отдавать ZIP с обращением (`.docx`) и файлами «Приложение_N.pdf». Без решений отдаётся
`.docx`.

#### Scenario: PDF с двумя решениями
- **WHEN** у пользователя загружены два решения, и админ скачивает PDF «Запроса данных по ОБДС»
- **THEN** в «Приложениях» две строки «Приложение №1/№2: …», а PDF содержит обращение и следом страницы обоих
  решений по порядку

#### Scenario: Скачивание Word с приложениями
- **WHEN** админ скачивает Word-версию при наличии решений
- **THEN** скачивается ZIP с `.docx` обращения и файлами «Приложение_1.pdf», «Приложение_2.pdf»

### Requirement: Доступ к файлам только для админа
Загрузка, скачивание и удаление файлов ОБДС SHALL быть доступны только суперпользователям через админку.
Прямые публичные ссылки на файлы SHALL не выдаваться.

#### Scenario: Обычный пользователь запрашивает файл
- **WHEN** не-суперпользователь открывает адрес скачивания решения или PDF сделки
- **THEN** его перенаправляет на вход в админку, файл не отдаётся
