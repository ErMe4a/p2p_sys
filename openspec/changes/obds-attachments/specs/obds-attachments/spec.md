## Purpose

Хранит файлы по делу ОБДС трейдера: решения ЦБ на каждый REQ и PDF со скринами сделок к записям переводов.
Прикладывает решения ЦБ к «Запросу данных по ОБДС», поддерживая несколько REQ в одном документе.

## ADDED Requirements

### Requirement: Решение ЦБ на каждый REQ
В блоке «База данных ОБДС» верхним пунктом система SHALL позволять админу загрузить PDF «Решение ЦБ» для
выбранного пользователя и указанного REQ. Для каждой пары «пользователь + REQ» хранится одно решение. Решение
SHALL можно скачать, заменить новым файлом и удалить. Принимаются только PDF размером до 20 МБ.

#### Scenario: Загрузка решения
- **WHEN** админ выбирает пользователя, указывает REQ-0001 и загружает PDF
- **THEN** решение сохраняется и отображается в списке решений пользователя с REQ, именем файла и кнопками
  «Скачать», «Заменить», «Удалить»

#### Scenario: Повторная загрузка на тот же REQ
- **WHEN** админ загружает другой PDF для REQ, у которого решение уже есть
- **THEN** старый файл заменяется новым, второе решение на тот же REQ не появляется

#### Scenario: Не PDF или слишком большой файл
- **WHEN** админ пытается загрузить файл не в формате PDF или больше 20 МБ
- **THEN** файл не сохраняется, и в блоке показывается причина

### Requirement: PDF сделки у записи перевода
Система SHALL позволять прикрепить к каждой записи ОБДС один PDF со скринами сделки, скачать его, заменить и
удалить. Ограничения те же: PDF, до 20 МБ. При удалении записи её файл SHALL удаляться вместе с ней.

#### Scenario: Прикрепление PDF к записи
- **WHEN** админ загружает PDF у записи перевода
- **THEN** у записи появляется отметка о файле и ссылка «Скачать»

#### Scenario: Удаление записи с файлом
- **WHEN** админ удаляет запись, к которой прикреплён PDF
- **THEN** запись и её файл удаляются

### Requirement: Несколько REQ в «Запросе данных по ОБДС»
Поле формы SHALL называться «Номера запросов ЦБ» и принимать один или несколько номеров через запятую. При
выборе пользователя поле SHALL заполняться всеми его REQ из «Базы данных ОБДС», если админ ещё не вводил его
вручную. В документе номера SHALL перечисляться через запятую: «по запросу REQ-1, REQ-2.».

#### Scenario: У пользователя два REQ
- **WHEN** админ выбирает пользователя, у которого в базе REQ-1 и REQ-2, и формирует «Запрос данных по ОБДС»
- **THEN** поле заполнено значением «REQ-1, REQ-2», а в документе стоит «по запросу REQ-1, REQ-2.»

### Requirement: Нумерованные приложения и скачивание вместе с решениями
В разделе «Приложения:» документа система SHALL выводить отдельную строку на каждое имеющееся решение ЦБ по REQ
из поля формы, по порядку перечисления: «Приложение №1: Решение ЦБ об отказе в исключении данных из базы
(REQ-1)», «Приложение №2: …». Если ни одного решения не загружено, раздел SHALL оставаться как в шаблоне
Максима.

«Скачать PDF» SHALL отдавать один PDF-файл: обращение, а за ним страницы приложенных решений в порядке
нумерации. «Скачать Word» при наличии приложений SHALL отдавать ZIP с обращением (`.docx`) и файлами решений,
имена которых начинаются с номера приложения. Без приложений отдаётся `.docx`, как раньше.

#### Scenario: PDF с двумя решениями
- **WHEN** у пользователя загружены решения по REQ-1 и REQ-2, и админ скачивает PDF «Запроса данных по ОБДС» с
  этими номерами
- **THEN** в тексте «Приложения» указаны «Приложение №1 … (REQ-1)» и «Приложение №2 … (REQ-2)», а скачанный
  PDF содержит обращение и следом страницы обоих решений по порядку

#### Scenario: Решение есть не по всем REQ
- **WHEN** в поле указаны REQ-1 и REQ-2, а решение загружено только по REQ-2
- **THEN** в тексте перечислены оба REQ, в приложениях одна строка «Приложение №1 … (REQ-2)», и приложено
  только это решение

#### Scenario: Скачивание Word с приложениями
- **WHEN** админ скачивает Word-версию при наличии решений
- **THEN** скачивается ZIP с файлом обращения `.docx` и файлами «Приложение_1_REQ-….pdf» и т.д.

### Requirement: Доступ к файлам только для админа
Загрузка, скачивание и удаление файлов ОБДС SHALL быть доступны только суперпользователям через админку.
Прямые публичные ссылки на файлы SHALL не выдаваться.

#### Scenario: Обычный пользователь запрашивает файл
- **WHEN** не-суперпользователь открывает адрес скачивания решения или PDF сделки
- **THEN** его перенаправляет на вход в админку, файл не отдаётся
