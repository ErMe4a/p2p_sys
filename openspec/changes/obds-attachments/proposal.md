## Why

У трейдера бывает несколько отказов ЦБ (несколько REQ), и к каждому есть файл «Решение ЦБ». В «Запросе данных
по ОБДС» эти решения указаны в приложениях, и банку их нужно отправлять вместе с обращением. Ещё Максим хочет
хранить PDF со скринами каждой подозрительной сделки, чтобы потом использовать их в следующих формах. Сейчас
файлы нигде не хранятся, а форма поддерживает только один REQ.

## What Changes

- **«Решение ЦБ» в блоке «База данных ОБДС».** Верхний пункт блока: загрузка PDF-файла решения ЦБ на каждый
  REQ выбранного пользователя. Решение можно скачать, заменить и удалить.
- **PDF к каждой записи перевода** (скрины сделки): загрузить, скачать, заменить, удалить. В документах пока
  не используются, понадобятся в следующих формах.
- **«Запрос данных по ОБДС» с несколькими REQ:**
  - поле «Номер запроса ЦБ» становится «Номера запросов ЦБ» (через запятую) и при выборе пользователя
    заполняется всеми его REQ из базы; поле можно править;
  - в тексте документа — «по запросу REQ-1, REQ-2.»;
  - в разделе «Приложения:» — отдельная строка на каждое загруженное решение ЦБ, нумерация «Приложение №1,
    №2…» по порядку REQ.
- **Скачивание вместе с решениями:**
  - «Скачать PDF» отдаёт **один PDF**: сначала обращение, за ним страницы приложенных решений ЦБ;
  - «Скачать Word» при наличии решений отдаёт **ZIP**: обращение `.docx` и файлы решений; без решений —
    `.docx`, как сейчас.
- Новая зависимость **`pypdf`** для склейки PDF (с согласия владельца).
- Новые модели и миграция: решения ЦБ (пользователь + REQ + файл) и поле файла у записи ОБДС.

## Capabilities

### New Capabilities
- `obds-attachments`: файлы ОБДС (решения ЦБ на REQ, PDF сделок к записям) и их использование в «Запросе
  данных по ОБДС»: несколько REQ, нумерованные приложения, склейка в один PDF или ZIP.

## Impact

- **Код:**
  - `orders/models.py` — `ObdsDecision`, `ObdsRecord.attachment`, миграция;
  - `orders/views.py` — загрузка, скачивание и удаление файлов, сборка приложений при экспорте;
  - `orders/documents/` — повтор абзаца в шаблоне, склейка PDF;
  - шаблон `obds_request.docx` — токены приложения и REQ;
  - `custom_admin/documents.html`;
  - `orders/urls.py`;
  - `requirements.txt` (UTF-16).
- **Хранилище:** файлы в общем media-хранилище (Yandex S3, как скриншоты ордеров). Отдаются только через
  админский view, прямых публичных ссылок нет.
- **Деньги и чеки:** не затрагиваются.
- **Деплой:** `pip install pypdf` на сервере, миграция (подтверждение владельца), рестарт `p2p`.
